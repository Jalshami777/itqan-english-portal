# منصة إتقان (Itqan English) - Next.js + Android (Capacitor)

منصة تعليمية متكاملة لتعلم اللغة الإنجليزية من الصفر (**A1**) إلى الاحتراف (**C2**)، مبنية باستخدام **Next.js 14 (App Router)** و **TypeScript** و **Tailwind CSS**، ومهيأة بالكامل للتصدير كبناء ثابت (`Static Export`) وتحويلها مباشرة إلى تطبيق أندرويد أصلي (`APK / AAB`) عبر **Capacitor**.

## المميزات الرئيسية
- **لوحة تحكم احترافية (Dashboard):** متابعة المستوى اللغوي، نقاط الخبرة (`XP`)، سلسلة الأيام المتتالية (`Streak`)، وتحليل المهارات الأربعة (الاستماع، التحدث، القراءة، الكتابة).
- **مسار تعلم تفاعلي (A1 إلى C2):** دروس متدرجة مع بطاقات مفردات ناطقة واختبارات تفاعلية فورية.
- **مختبر النطق والمحادثة:** نطق صوتي حقيقي باللكنة الأمريكية (`US`) والبريطانية (`UK`) عبر Web Speech API.
- **جاهزية كاملة للأندرويد:** متوافق مع `Capacitor` لبناء تطبيق أندرويد مباشر.

## خطوات التشغيل المحلي وبناء تطبيق الأندرويد

### 1. تثبيت الحزم وتشغيل بيئة التطوير
```bash
npm install
npm run dev
```
افتح المتصفح على `http://localhost:3000`.

### 2. تحويل المنصة إلى تطبيق أندرويد (Android APK / AAB)
```bash
npm run build
npx cap add android
npx cap sync android
npx cap open android
```
بعد فتح المشروع في **Android Studio**، اختر من القائمة العلوية:
`Build > Build Bundle(s) / APK(s) > Build APK(s)`
